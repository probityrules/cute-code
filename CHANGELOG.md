# Changelog

All notable changes to Cute Code are documented in this file.

## [0.3.0] — 2026-09-15

### Changed
- Open structure view as a same-tab custom editor instead of a side panel
- Add **Show Source** to return to the text editor

## [0.2.1] — 2026-09-11

### Added
- Architecture lenses (trace, coupling, data flow, interface surface)
- Focus neighborhood and hub demotion / hide controls
- Icon-only toolbar with tooltips for lenses and focus/hubs
- Smooth layout tweens so edges move with nodes

### Changed
- Arrow bindings split into named binding + anonymous `() => {}` with type icons

## [0.2.0] — 2026-09

### Added
- Module frame with import/export rails
- Editable titles that write back to source
- Broader JavaScript / JSX syntax coverage

## [0.1.0] — 2026-09

### Added
- Initial structural AST graph for JavaScript
- Execution, variable, and inheritance layouts
- Expand/collapse, edge-kind toggles, and go-to-source
